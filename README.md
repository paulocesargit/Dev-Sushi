# DevSushi

O **DevSushi** é um projeto que eu criei para treinar meus conhecimentos em desenvolvimento. É uma plataforma einterativa.

é um restaurante de sushi, trazendo uma fusão única entre o aprendizado de desenvolvimento e a paixão pela culinária japonesa. O projeto foi feito como uma maneira de aprimorar minhas habilidades técnicas enquanto crio algo prático e envolvente. A interface é responsiva e moderna, proporcionando uma navegação fluída em qualquer dispositivo.

---

## 📌 Recursos

### Páginas Públicas:

- Seção de apresentação do projeto e suas funcionalidades.
- Interface responsiva otimizada para diferentes dispositivos.

### Notificações:

- Notificações em tempo real para interações e atualizações importantes, utilizando **React Toastify**.

### Componentização:

- Uso de componentes reutilizáveis para promover organização e escalabilidade.

### Estilização Eficiente:

- **TailwindCSS** para uma estilização rápida e responsiva.

---

## 🛠 Tecnologias Utilizadas

- **React**: Biblioteca para construção de interfaces de usuário.
- **Vite**: Ferramenta moderna e rápida para build e desenvolvimento.
- **TailwindCSS**: Framework de CSS para estilização rápida e responsiva.
- **React Router DOM**: Gerenciamento de rotas para navegação entre as páginas.
- **React Icons**: Biblioteca para ícones vetoriais.
- **React Toastify**: Biblioteca para notificações fáceis de integrar e personalizar.

## 📦 Instalação e Execução

### 1. Clone o repositório:

```bash
git clone https://github.com/seu-usuario/devsushi.git
cd devsushi
```

### 2. Instale as dependências do projeto:

```bash
npm install
```

### 3. Execute o projeto:

```bash
npm run dev
```

### 4. Acesse no navegador:

```
http://localhost:3000
```

> **Obs.:** A porta pode variar dependendo da disponibilidade.
